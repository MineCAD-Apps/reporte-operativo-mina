CONTENIDO

GUIA_VOLADURAS.md          Guía de uso, desarrollo y alcance.

PARA PUBLICAR MANUALMENTE EN GITHUB
1. Descomprime MineCAD-voladuras-Tovex100.zip.
2. Sube el CONTENIDO a la raíz de reporte-operativo-mina, conservando
   las carpetas y sustituyendo únicamente el index.html del menú.
   No subas el ZIP cerrado como si fuera la aplicación.
3. Si el menú remoto se modificó después de esta actualización,
   conserva sus cambios y añade el enlace a voladuras/index.html.
4. Espera a que termine la publicación de GitHub Pages y recarga MINECAD.

No es necesario otro repositorio, servidor ni servicio de pago.
No se publicó ni se hizo push desde esta conversación.

TOVEX 100
Presentación: bombillo de 1 pulgada x 8 pulgadas (25.4 x 203.2 mm).
El peso por pieza y el precio quedan pendientes para capturar los
datos reales de tu presentación. La aplicación no inventa ese peso.

Abre el módulo desde MINECAD; no abras su index.html con doble clic,
porque los módulos JavaScript requieren un servidor HTTP/HTTPS.

El borrador y las versiones se guardan en el navegador y equipo en
uso. Exporta JSON para respaldar o cambiar de equipo. Los sólidos
STL/OBJ se vuelven a cargar al abrir el diseño.

Incluye edición 2D/3D, consumo manual por barreno, costos, biblioteca,
registro de campo, importación/exportación JSON, CSV para Excel y
reporte imprimible/PDF. La reproducción de tiempos es visual y no
incluye modelos físicos de fragmentación, vibración o flujo de roca.
